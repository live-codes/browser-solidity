Two ways in. Both compile in a classic worker and deploy on an in-page EVM; neither talks to a server.

1. Classic worker, full bundle (the LiveCodes shape)

importScripts('solc-wasm.global.js') then self.solcWasm.createCompiler().



		
2. Module entry point, which spawns its own worker

		

			import { createCompiler } from '../src/index.js' — the compiler goes to a worker the
			entry point owns, the EVM stays here.
